# StreetWear Clothing Website

This repository contains the source code for a static front-end of a streetwear e-commerce website. Built purely with HTML and CSS, it serves as a visual prototype, showcasing a clean and modern design for an online clothing store. The site features multiple pages including a homepage, product galleries, a shopping cart, and a login page.

## Features

- **Homepage:** A welcoming landing page with a featured product image and a call-to-action button for new collections.
- **Product Pages:** Dedicated pages for "Clothing" and "Accessories," displaying items in a responsive grid layout. Each product includes an image, title, price, and a star rating.
- **Shopping Cart:** A static cart page that presents items in a tabular format, including details like product image, title, price, quantity, and subtotal.
- **Login Page:** A simple and clean login form for user authentication, with an option to connect via social media.
- **Consistent UI:** A unified design language is maintained across all pages with a persistent navigation bar and footer.

## Pages

The website consists of the following pages:

- **`home.html`**: The main landing page.
- **`clothes.html`**: Displays a collection of clothing items for sale.
- **`accessories.html`**: Showcases accessories such as hats and socks.
- **`cart.html`**: Provides a summary of the items selected for purchase.
- **`login.html`**: A user authentication page.

## Technologies Used

- HTML5
- CSS3

## Getting Started

To view the website, simply clone the repository and open the `home.html` file in your preferred web browser.

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/umarahmed1218/streetwear-clothing-website.git
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd streetwear-clothing-website
    ```
3.  **Open `home.html` in your browser.**
